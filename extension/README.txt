AliasHub Outlook Connector

1. Extract this ZIP to a permanent folder.
2. Open chrome://extensions in Chrome or Edge.
3. Enable Developer mode.
4. Choose Load unpacked and select the extracted folder.
5. Copy the connector pairing key from AliasHub Settings.
6. Open the extension popup, enter the local AliasHub URL and pairing key,
   then save and confirm it shows connected.
7. Open the Microsoft page from the selected AliasHub account or from this popup.

The connector operates only on the Microsoft alias page and reports confirmed
results to this AliasHub installation. It stops and shows an account-mismatch
message when the Microsoft page is signed in with a different account. The
switch button signs out the current Microsoft web session before opening the
selected task account; it does not change the OAuth tokens stored by AliasHub.

The connector is optional. Manual alias creation and registration do not need it.
